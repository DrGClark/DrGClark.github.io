## Current Courses (University of South Alabama)

### Graduate Courses

**CSC 612 - Cybersecurity** (2 sections taught)  
Advanced topics in cybersecurity including network security, cryptography, secure software development, and security architecture. Emphasizes both theoretical foundations and practical applications.

**CSC 520 - Computer Architecture** (2 sections taught)  
In-depth study of computer organization and architecture, including processor design, memory hierarchies, instruction set architectures, and performance analysis.

**CSC 585 - Cyber-Physical Security** (3 sections taught)  
Security challenges and solutions for cyber-physical systems, including industrial control systems, autonomous vehicles, and IoT devices. Topics include attack vectors, intrusion detection, and defense mechanisms.

**CSC 560 - Security of Hardware Implementations** (1 section taught)  
Hardware security topics including side-channel analysis, hardware trojans, FPGA security, and secure hardware design. Includes laboratory work with power analysis and EM radiation measurement.

**CSC 582 - Network Security** (1 section taught)  
Network security protocols, intrusion detection systems, firewalls, VPNs, and secure network design. Emphasis on both defensive and offensive security techniques.

**CSC 590 - Special Topics in Computer Science** (1 section taught)  
Advanced topics in current research areas, varying by semester.

### Undergraduate Courses

**CSC 320 - Computer Organization and Architecture** (3 sections taught)  
Fundamentals of computer organization, assembly language programming, processor design, and memory systems.

**CSC 485 - Cyber-Physical Security** (3 sections taught)  
Introduction to security issues in cyber-physical systems with hands-on laboratories. Undergraduate companion to CSC 585.

**CSC 460 - Security of Hardware Implementations** (1 section taught)  
Introduction to hardware security concepts and side-channel analysis. Undergraduate companion to CSC 560.

**CSC 333 - Programming Language Theory** (1 section taught)  
Theoretical foundations of programming languages including syntax, semantics, type systems, and language design principles.

**CSC 490 - Special Topics** (1 section taught)  
Special topics in computer science chosen to reflect current developments in the field.

## Teaching Philosophy

My teaching approach emphasizes hands-on learning through laboratory exercises and real-world projects. I believe students learn cybersecurity best by doing—configuring systems, analyzing vulnerabilities, and implementing defenses. I integrate current research into coursework, exposing students to cutting-edge developments in hardware security, robotics security, and cyber-physical systems.

I am committed to mentoring the next generation of cybersecurity researchers and practitioners, providing guidance not only in technical skills but also in research methodology, academic writing, and professional development.
