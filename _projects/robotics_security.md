## Overview

This research focuses on identifying vulnerabilities and developing defense mechanisms for autonomous robotic systems, including self-driving vehicles and industrial robots. The work addresses both software-level attacks targeting machine learning models and hardware-level threats through side-channel analysis.

### Key Research Areas

#### Machine Learning Security
- Adversarial attacks on perception systems
- Defense mechanisms for deep learning models
- Robustness testing in simulated and physical environments

#### Hardware Security
- Side-channel analysis attacks (power, EM, acoustic)
- FPGA security and trojan detection
- Secure hardware implementations

#### Cyber-Physical Systems
- Intrusion detection for robotic communications
- Security of ROS (Robot Operating System) networks
- Automotive cybersecurity

### Publications

Related work has been published in IEEE conferences and the Journal of Defense Modeling and Simulation, examining simulation-based risk reduction and real-time attack detection methods.
